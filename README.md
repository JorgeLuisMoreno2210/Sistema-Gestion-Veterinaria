# Sistema de Gestión Integral para Veterinaria — Ventas, Atención y Citas

Plataforma web diseñada para optimizar la administración operativa y comercial de una clínica veterinaria. Integra en un solo entorno el agendamiento de consultas, el seguimiento de la atención médica de mascotas y el control de ventas de productos y servicios veterinarios.

## Características principales
* **Agendamiento de citas:** Módulo organizado para programar, consultar y gestionar turnos de consultas médicas, vacunación, estética y controles.
* **Gestión de atención y pacientes:** Registro estructurado de clientes (propietarios) y sus mascotas para agilizar el flujo de atención en clínica.
* **Módulo de ventas y facturación:** Control de ventas de medicamentos, alimentos, accesorios y servicios médicos con cálculo dinámico de totales.
* **Interfaz intuitiva y responsiva:** Diseño limpio y funcional pensado para facilitar el trabajo diario en recepción y consultorio desde distintos dispositivos.

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
